## Сравнение рекурсивной и нерекурсивной реализации построения бинарного дерева

### Параметры задания:
- Root = 14
- Height = 4 (варьируется в тестах)
- left_leaf = 2 - (root - 1)
- right_leaf = root * 2

---

## 1. РЕАЛИЗАЦИЯ

### Рекурсивная версия: `build_tree_recursive()`
```python
def build_tree_recursive(height, root=14, left_branch=..., right_branch=...):
    if height == 0:
        return {str(root): []}
    
    left_tree = build_tree_recursive(height - 1, left_branch(root), ...)
    right_tree = build_tree_recursive(height - 1, right_branch(root), ...)
    
    return {str(root): [left_tree, right_tree]}
```

**Особенности:**
- Использует рекурсию для левого и правого поддеревьев
- Код простой и понятный
- Встроенное использование стека вызовов

### Нерекурсивная версия: `build_tree_iterative()`
```python
def build_tree_iterative(height, root=14, left_branch=..., right_branch=...):
    root_dict = {str(root): []}
    queue = deque([(root, root_dict[str(root)], 0)])
    
    while queue:
        current_value, current_children, current_level = queue.popleft()
        if current_level >= height:
            continue
        
        left_value = left_branch(current_value)
        right_value = right_branch(current_value)
        
        left_dict = {str(left_value): []}
        right_dict = {str(right_value): []}
        
        current_children.append(left_dict)
        current_children.append(right_dict)
        
        queue.append((left_value, left_dict[str(left_value)], current_level + 1))
        queue.append((right_value, right_dict[str(right_value)], current_level + 1))
    
    return root_dict
```

**Особенности:**
- Использует явную очередь (deque)
- Избегает рекурсии
- Полный контроль над процессом построения

## 3. АНАЛИЗ РЕЗУЛЬТАТОВ

### Временная сложность:
- **Обе версии:** O(2^h) - одинаковая, так как оба метода создают одинаковое количество узлов
- На высоте h количество узлов = 2^(h+1) - 1

### Пространственная сложность:
- **Рекурсивная:** O(h) - глубина стека вызовов
- **Нерекурсивная:** O(2^h) - размер очереди на листьях

### Скорость выполнения:
- На малых высотах (h ≤ 6): разница минимальна (оверхед создания объектов)
- На средних высотах: рекурсия может быть быстрее (глубина стека оптимальна)
- На больших высотах: скорости сравнимы

### Ограничения:
- **Рекурсия:** Максимум ~1000 вызовов (зависит от платформы)
- **Итеративная:** Ограничена только доступной памятью (может обработать h > 20)

## 4. ВЫВОДЫ

### Рекурсивная версия подходит когда:
1. Высота дерева < 10
2. Требуется простота и читаемость кода
3. Важна локальность памяти

### Нерекурсивная версия подходит когда:
1. Высота дерева > 10
2. Нужна стабильность (избегаем переполнения стека)
3. Важна масштабируемость

### Общие выводы:
- Обе реализации имеют одинаковую временную сложность O(2^h)
- Для практических деревьев (h < 15) разница в скорости минимальна
- Выбор метода зависит от требований задачи, а не от скорости выполнения
- Рекурсивное решение проще, нерекурсивное надёжнее
